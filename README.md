# Cookies & Lemonades

Fresh static GitHub Pages website for cookiesandlemonade.com.

## Upload
Upload `index.html`, `styles.css`, `script.js`, and `CNAME` to the **root** of your GitHub Pages repository. Keep `index.html` spelled exactly that way.

## Custom domain
GitHub Pages → Settings → Pages → Custom domain:
`cookiesandlemonade.com`

The CNAME file also contains:
`cookiesandlemonade.com`

## Form
The inquiry form is already connected to Formspree:
https://formspree.io/f/xkjojovj

Set your Target Email in Formspree so submissions arrive at your email.

## Photos
The site is intentionally working without image files. The photo areas are placeholders you can replace with your own photos later.
