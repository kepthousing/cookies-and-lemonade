# Cookies & Lemonades

Elegant static catering website mockup for GitHub Pages.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive styling
- `script.js` — mobile navigation, section highlighting, demo form
- `hero.jpg` — temporary hero/mockup image

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all four files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

## Before launch
Replace the temporary image blocks with your real cookie/lemonade photography, add your actual contact information, and connect the inquiry form to an email/form service.
